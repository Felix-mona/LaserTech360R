# LaserTech360R

A software to combine Disto measurements with XPAD GPS data

Summary V1.00:
Script runs within excel button, finds two seperate files. One being the disto file and one being the XPAD file. Opens both filters out necessary data, combines it in required way. Outputs to CSV file and writes a validation report to then show on a different sheet within the excel.
